What changed from the Phase-A study

D1Utility type 8.5–9px → 11px (one 10px in-mark exception, used here only by the SAMPLE chip). Team column 74 → 84, value column 74 → 78, bar 166 → 146, gap 10 → 12. The delta drops the words vs LG — the strap names the benchmark and the gold tick sits on every bar, so it was said three times. Card height 360 → 371px.

AATertiary ink #6E8078 → #849489 on dark (4.11:1 → 5.38:1) and #71807A → #616E69 on light (3.82:1 → 4.91:1 on paper). The mockup's utility layer did not pass AA at any size it was used at. The originals survive as --yy-*-dim for non-text use only.

D3Red splits by role, not by shade: the fill is #D9503C (4.22:1, legal as a graphical object), the figure is #E8A08D (8.05:1, legal as text). Absence goes neutral — the salmon void grammar means "void / dead", which is a negative, and a suppressed ratio is not one.

D6Figures in a column are Inter 600 with tnum; standalone figures stay Rajdhani. Both are set from --yy-font-num / --yy-font-athletic, so a one-token change moves the whole product if Rajdhani is verified for tabular figures.
